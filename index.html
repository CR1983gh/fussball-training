💡 So trainierst du richtig
1. Rücken zum Bildschirm stellen, auf das Signal (Ton!) warten, schnell umdrehen.
2. Die Aktion ist vorher abgesprochen — z. B. ungerade = Sprint nach links.
3. Nur kurz hinschauen (unter 1,5 Sekunden) — so wie im Spiel, bevor der Ball kommt.
4. Steigere die Entfernung: erst 3 Meter, später 8–12 Meter.
5. 2× pro Woche für 10–15 Minuten reicht schon — regelmäßig schlägt viel!
